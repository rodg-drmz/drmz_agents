# Pedagogical Frameworks Knowledge Base

This directory contains frameworks and strategies for modern, engaging, and inclusive pedagogy.

## Frameworks Included

1. **Project-Based Learning (PBL)**
   - Authentic, real-world projects
   - Student voice and choice
   - Sustained inquiry
   - Reflection and revision

2. **Social Emotional Learning (SEL)**
   - CASEL five core competencies
   - Self-awareness and self-management
   - Social awareness and relationship skills
   - Responsible decision-making

3. **Gamification Strategies**
   - Points, badges, and leaderboards
   - Levels and progression systems
   - Challenges and quests
   - Engagement and motivation

## Usage

These frameworks are used by the syllabus evaluation system to:
- Assess pedagogical approaches in syllabi
- Recommend modern teaching strategies
- Evaluate student engagement methods
- Suggest improvements for inclusive, engaging learning

## Integration

The `evaluate_inclusivity_flow.py` searches for these frameworks when evaluating syllabi, allowing the AI to:
- Identify PBL elements in course design
- Assess SEL integration
- Evaluate gamification strategies
- Provide recommendations based on these frameworks
