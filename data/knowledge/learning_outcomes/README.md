## Adding Learning Outcomes

1. Create discipline folder if needed
2. Add course-specific outcomes file
3. Format: Markdown with clear learning outcome statements
4. Include: Course number, level, and specific measurable outcomes

## Example Format

```markdown
# ENGL 101 - Composition Learning Outcomes

## Course-Level Outcomes
1. Students will write clear, well-organized essays with thesis statements
2. Students will analyze and synthesize sources effectively
3. Students will demonstrate understanding of academic writing conventions
4. Students will revise and edit their work for clarity and correctness
5. Students will engage critically with diverse perspectives

## Assessment Alignment
- Essay assignments → Outcomes 1, 2, 3
- Research project → Outcomes 2, 3, 4
- Peer review → Outcomes 4, 5
```
