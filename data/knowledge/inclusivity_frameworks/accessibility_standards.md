# Accessibility Standards for Syllabi

## ADA (Americans with Disabilities Act) Requirements

### Required Elements
1. **Accessibility Statement**
   - Clear statement about accommodations
   - Contact information for disability services
   - Process for requesting accommodations
   - Timeline for accommodation requests

2. **Accessible Materials**
   - Digital materials in accessible formats
   - Alternative text for images
   - Captions for videos
   - Readable fonts and formatting

3. **Flexible Assessment**
   - Multiple assessment formats
   - Extended time options
   - Alternative formats available
   - Clear expectations and rubrics

## WCAG (Web Content Accessibility Guidelines)

### Level AA Compliance
- Text alternatives for images
- Captions for videos
- Sufficient color contrast
- Keyboard navigation support
- Clear headings and structure

## Syllabus Checklist

- [ ] Accessibility statement included
- [ ] Disability services contact information
- [ ] Accommodation request process explained
- [ ] Materials available in accessible formats
- [ ] Flexible assessment options mentioned
- [ ] Support resources clearly listed
