# Inclusivity Frameworks Knowledge Base

This directory contains frameworks and standards for evaluating syllabus inclusivity.

## Frameworks Included

1. **Universal Design for Learning (UDL)**
   - Multiple means of representation
   - Multiple means of engagement
   - Multiple means of action and expression

2. **Culturally Responsive Teaching (CRT)**
   - Cultural competence
   - Student-centered instruction
   - Critical consciousness

3. **Accessibility Standards**
   - ADA (Americans with Disabilities Act)
   - WCAG (Web Content Accessibility Guidelines)
   - Section 508 compliance

4. **Inclusive Language Guidelines**
   - Bias-free language
   - Gender-inclusive terms
   - Culturally sensitive terminology
