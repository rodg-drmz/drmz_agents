# Assessment Frameworks

This directory contains frameworks and tools for assessment design and evaluation.

## Contents

### AI Assessment Scale (AIAS)
- **File**: `ai_assessment_scale.md`
- **Source**: Furze, L., Perkins, M., Roe, J., & MacVaugh, J. (2024, August 28). Updating the AI Assessment Scale. Leon Furze. https://leonfurze.com/2024/08/28/updating-the-ai-assessment-scale/
- **Description**: A 5-level framework for determining appropriate AI use in assessments, ranging from "No AI" to "AI Exploration"
- **Use Cases**: 
  - Rubric generation
  - Assessment design
  - AI usage policy development
  - Student guidance on AI use
